# 📺 Couch-TV: Windows TV Box & Mobile Remote Controller

[![GitHub Repo](https://img.shields.io/badge/GitHub-chicodog530%2FCouch--TV-blue?logo=github)](https://github.com/chicodog530/Couch-TV)
[![Python 3.10+](https://img.shields.io/badge/Python-3.10%2B-green.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Transform your Windows PC into a 10-foot TV Box / Home Theater PC, controlled directly from your phone via local Wi-Fi. 100% private, zero cloud servers, zero telemetry.

---

## ✨ Features

### 💻 Windows PC Side
* **10-Foot Fullscreen TV Launcher**:
  * Designed for viewing from your couch on a 1080p / 4K TV.
  * **Selectable HD Ambient Wallpapers**: Choose from **Northern Aurora, Deep Space Nebula, Cyberpunk Neon, Cinema Sunset**, or **Midnight OLED**.
  * Big streaming tiles for **Hulu, Amazon Prime Video, Netflix, YouTube, Disney+, Max, Twitch, Spotify, Plex, Steam**, and custom apps.
  * **True 100% Fullscreen Launching**: Shortcuts launch in dedicated fullscreen kiosk windows without browser bars or borders.
  * **"⬅ Back to TV Main Screen" Floating Overlay**: When any streaming app is open, an always-on-top button sits in the top-left corner of your TV screen. Click it anytime to close/minimize the app and return to the TV launcher.
  * **Switch to PC Mode**: Click **"💻 CLICK HERE FOR PC MODE"** or press <kbd>ESC</kbd> / <kbd>F11</kbd> to minimize to desktop.
  * **"📺 Return to TV Mode" Pill**: When in PC mode, a floating button stays pinned in the corner of your desktop so you can jump back with one click.
  * **Live QR Code Pairing**: Displays an instant pairing QR code on the TV screen.

### 📱 Android Phone Side (Progressive Web App)
* **Zero Cloud / 100% Local**: All communication stays strictly on your home Wi-Fi.
* **App Shortcuts Management (Add, Delete & Sort)**:

## 🚀 Quick Installation & Setup

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/chicodog530/Couch-TV.git
   cd Couch-TV
   ```

2. **Run the Installer**:
   * Double-click **`installer.bat`**:
     * Automatically detects Python 3.10+.
     * Creates an isolated virtual environment in `.venv/`.
     * Upgrades `pip` and installs all packages from `requirements.txt`.
     * Verifies package integrity.

3. **Start Couch-TV**:
   * Double-click **`run.bat`**:
     * Automatically uses the `.venv` virtual environment.
     * Starts the TV Box fullscreen launcher on your TV.
     * Starts the secure local HTTP/HTTPS & WebSocket server.
     * Shows the instant pairing QR code on your TV screen.
   * *(Optional)* Double-click **`run_headless.bat`** if you only want the mobile remote server running silently in the system tray without the TV window.

4. **Connect Your Phone**:
   * Point your Android/iPhone camera at the QR code on the TV.
   * Open the link in Chrome or your mobile browser.
   * Tap the browser menu `⋮` -> **"Add to Home Screen"** to install the mobile remote as a native app!

## 🛠️ Switching Between TV Mode & PC Desktop

| Action | How to do it |
| :--- | :--- |
| **Switch to PC Mode** | Tap **"💻 PC Mode"** on your phone remote, or press `ESC` on the keyboard, or click the top-right button on the TV screen. |
| **Switch to TV Mode** | Tap **"📺 TV Mode"** on your phone remote, or double-click the CouchPC icon in the Windows taskbar / system tray. |
